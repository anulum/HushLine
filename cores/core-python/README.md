# Hushline Python Core

Scaffold for a Python implementation.

Planned implementation:

- `src/hushline_core/__main__.py` entrypoint
- `src/hushline_core/config.py`
- `src/hushline_core/muter.py`
- `src/hushline_core/pipeline.py`

Run command:

```bash
python -m hushline_core
```

This core has no telemetry/network reporting dependencies by design.
