# Security Policy

Hushline has no network reporting, no external telemetry, and no usage analytics.

If you discover a security issue, report it to the internal project owner via the
team's normal private security contact.

Minimum expectations:
- Keep `~/.config/hushline` and `.hushline` directories local and private.
- Vet output redaction patterns for secrets before sharing logs.
- Review quieting rules before accepting generated defaults.
